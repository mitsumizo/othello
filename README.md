# オセロ

戦略的なAI対戦相手と対戦できるオセロ（リバーシ）ゲームです。ReactとViteで構築されています。

**[🎮 今すぐプレイ](https://mitsumizo.github.io/othello/)**

## 特徴

### ゲーム機能
- 完全なオセロゲームロジック（8×8ボード）
- 正確な石のひっくり返し処理
- 有効な手のみ配置可能（ヒント表示付き）
- 置ける場所がない時の自動パス
- ゲーム終了判定と勝敗表示
- リアルタイムスコア表示

### AI対戦相手
- **位置評価システム**: 四隅（角）を最優先、エッジも重視
- **先読みアルゴリズム**: 2手先まで読んで最善手を選択
- **機動性評価**: 次のターンで打てる場所の数も考慮
- 戦略的で手強いプレイスタイル

### UI/UX
- モダンで美しいインターフェース
- アニメーション効果（石の配置、ヒントの点滅）
- グラデーション背景
- レスポンシブデザイン（モバイル対応）

## インストール

```bash
# リポジトリをクローン
git clone https://github.com/mitsumizo/othello.git
cd othello

# 依存関係をインストール
npm install
```

## 使い方

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173/` を開いてゲームをプレイできます。

### ビルド

```bash
npm run build
```

### プレビュー

```bash
npm run preview
```

## 遊び方

1. あなたは**黒**（先攻）、AIは**白**（後攻）です
2. 盤面に表示される白い点（ヒント）がクリック可能な場所です
3. 石を置くと、挟んだ相手の石が自分の色にひっくり返ります
4. 置ける場所がない場合は自動的にパスされます
5. 両者が置けなくなったらゲーム終了、石が多い方が勝ちです

## AIの戦略

AIは以下のアルゴリズムで最適な手を選択します：

1. **位置評価マトリックス**: 各マスに重み付けされた点数
   - 四隅（角）: +100点（最重要）
   - 角の隣接マス: -50点（取られると角を取られやすい）
   - 辺（エッジ）: +10点

2. **先読み探索**: 自分の手と相手の最善手を予測して評価

3. **機動性ボーナス**: 次のターンで打てる場所が多いほど有利
